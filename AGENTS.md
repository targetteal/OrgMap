# Trabalhar no OrgMap

Comece pelo [guia de contribuição](CONTRIBUTING.md), pelo [mapa da arquitetura](docs/architecture.md) e pelo [guia de testes](docs/testing.md). Para UI, consulte o [design system](DESIGN.md).

Preserve autorização, RLS, escopo de organização e isolamento entre contas. Use ports para integrar domínios. Preserve os IDs e contratos de conteúdo rico e aplique migrations aditivas.

Use dados fictícios para testes. Preserve bancos, uploads e backups e guarde credenciais fora do Git.
