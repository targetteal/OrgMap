# Comunicar uma vulnerabilidade

Use **Security → Report a vulnerability** no GitHub quando o canal privado estiver habilitado. Até lá, fale em privado com a manutenção do projeto.

Inclua a versão ou o commit afetado, o comportamento observado e os passos para reproduzir com dados fictícios. Mantenha chaves, sessões e dados de organizações fora do relato. Use as [issues](https://github.com/targetteal/OrgMap/issues) para bugs comuns.
